# 🚀 PulseVault

A premium real-time cryptocurrency market analytics dashboard built with HTML, CSS, and JavaScript.

PulseVault delivers a modern and responsive user experience with live cryptocurrency prices, interactive charts, portfolio tracking, watchlists, and market analytics—all in a clean, professional interface.

## 🌐 Live Demo

https://inovus-technologies.github.io/PulseVault/

---

## ✨ Features

- 📈 Live cryptocurrency market data
- ⚡ Real-time WebSocket price updates
- 📊 Interactive charts
- 💼 Portfolio tracker
- ⭐ Watchlist management
- 🔍 Smart search & sorting
- 🌙 Dark & Light themes
- 📱 Fully responsive design
- 💾 Local storage persistence
- 🌍 Global market overview
- 🎨 Premium glassmorphism UI

---


## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- WebSocket API
- REST APIs

---

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Inovus-Technologies/PulseVault.git
```

Open `index.html` in your browser.
